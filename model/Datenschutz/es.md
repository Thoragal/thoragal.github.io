## 2. Ámbito de aplicación

Esta política de privacidad se aplica al uso de este sitio web. Solo se tratan los datos personales descritos a continuación.

Al rellenar el formulario de contacto se recogen su nombre, apellido, dirección de correo electrónico y su mensaje. Estos datos se reenvían exclusivamente por correo electrónico al responsable y **no** se almacenan en ninguna base de datos. La finalidad es responder a su consulta.

## 4. Datos recogidos automáticamente

Al visitar el sitio web, los servicios de alojamiento utilizados (véase el punto 6) tratan técnicamente la dirección IP, la fecha/hora de acceso y la información del navegador. Estos datos sirven para el funcionamiento seguro del sitio web (p. ej. protección contra abusos mediante limitación de solicitudes) y no se combinan con otras fuentes de datos.

## 5. Sin cookies, sin seguimiento

Este sitio web no utiliza cookies, ninguna herramienta de análisis ni tecnologías de seguimiento o publicidad. El navegador solo utiliza `sessionStorage`, técnicamente necesario para el inicio de sesión de administrador del operador; esto no afecta a los visitantes del sitio web.
